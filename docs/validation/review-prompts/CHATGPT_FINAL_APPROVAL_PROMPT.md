# ChatGPT Final Approval Prompt

Review the final repository, implementation report, test logs, acquisition report, UAT report, and independent code review.

Verify:

- no source originals entered Git;
- core files are stored privately;
- audio/video were deferred;
- disk reserve remained intact;
- downloads are resumable and verified;
- catalog and manifests reconcile;
- backup is restorable;
- third-party originals were not altered;
- original copyright templates use the approved owner/publisher identity correctly;
- documentation matches actual commands and behavior;
- critical/high findings are closed.

Return one final decision:

- APPROVED
- APPROVED WITH DOCUMENTED LIMITATIONS
- NOT APPROVED

List evidence for every decision point and the exact next action.

# CoWork UAT Prompt

Act as an end-user acceptance tester on Windows.

Validate without editing production code:

1. Fresh clone/bootstrap.
2. `bhava.ps1 doctor`.
3. Metadata scan.
4. Core estimate.
5. Core acquisition or safe resume.
6. Ctrl+C interruption and recovery.
7. Low-disk simulation.
8. Unknown-size file.
9. Broken/redirected link.
10. Duplicate file.
11. Malformed archive.
12. Search and reports.
13. Timestamped backup.
14. Restore verification.
15. Proof that `data/**` cannot be committed.
16. Proof that audio/video remain excluded.
17. Proof that third-party originals have no Dauji/Bhāva ownership stamp.
18. Original-work copyright notice generation.

Capture screenshots/log excerpts and exact commands.

Return:
- passed scenarios;
- failed scenarios;
- usability issues;
- data-integrity issues;
- release recommendation.

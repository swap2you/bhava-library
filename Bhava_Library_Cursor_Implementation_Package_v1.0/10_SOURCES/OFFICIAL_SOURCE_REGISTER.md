## Git and large files

- GitHub large-file guidance  
  https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github

The architecture intentionally avoids storing downloaded binaries in ordinary Git. GitHub warns at 50 MiB, blocks files above 100 MiB in ordinary Git, and recommends small repositories.

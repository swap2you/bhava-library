# Copyright Context for the Existing Nine Bhāva Stories

## Objective

Bring the existing nine original stories under the same evidence and notice system without altering their spiritual content.

## Required inventory

For each story record:

- title;
- story number;
- current file types;
- author/editor;
- original creation date;
- current publication/distribution status;
- source dossier;
- scriptural references;
- AI assistance;
- illustration/audio status;
- first shared date and audience;
- current version;
- SHA-256;
- missing contributor agreements;
- proposed notice;
- registration candidate status.

## Notice

For an unpublished draft:

`DRAFT — NOT FOR DISTRIBUTION`
`Copyright © YYYY Swarna Gauranga Das.`

For a published original story:

`Copyright © YYYY Swarna Gauranga Das. All rights reserved.`
`Published by Dauji Publication, a Bhāva Project publication.`

The year must reflect first publication, not the year when the notice was added.

## Retrofitting

The utility may:

- add copyright metadata to newly generated output files;
- add a copyright page when producing a new edition;
- add a footer to printables;
- generate sidecar manifests;
- preserve prior versions.

It must not silently modify a previously released file and pretend it was always the same edition. Create a new version and record the change.

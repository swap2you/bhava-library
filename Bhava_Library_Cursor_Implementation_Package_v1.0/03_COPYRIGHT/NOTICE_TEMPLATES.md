# Copyright Notice Templates

Replace `YYYY` with the actual year of first publication for that work.

## Standard book/comic copyright page

```text
Copyright © YYYY Swarna Gauranga Das
All rights reserved.

Published by Dauji Publication
A Bhāva Project publication

Harrisburg, Pennsylvania, USA
Contact: SwarnaGaurangaDas@gmail.com

First edition: YYYY
Version: [version]
Work ID: [work-id]

No part of this original publication may be reproduced, distributed, transmitted,
or stored except as permitted by applicable law or by written license from the
copyright owner.

Scriptural quotations, source texts, trademarks, and third-party materials remain
the property of their respective rights holders and are credited separately.
```

The final rights paragraph must be reviewed for the actual licenses and quotation permissions.

## Printable footer

```text
© YYYY Swarna Gauranga Das · Dauji Publication · Bhāva Project · [license type]
```

## Teacher subscription copy

```text
Licensed to: [adult subscriber/organization]
License ID: [license-id]
© YYYY Swarna Gauranga Das · Dauji Publication · Not for public redistribution
```

Do not include child names in visible license marks.

## Free personal-use printable

```text
© YYYY Swarna Gauranga Das · Dauji Publication · Free for personal and single-classroom use;
public reposting and resale are not permitted.
```

Use only after the corresponding license terms exist.

## Third-party reference sidecar

Do not edit the original. Store beside it:

```text
classification: private_reference_original
ownership_claimed_by_bhava: false
source_url: ...
retrieved_at: ...
embedded_copyright_notice: ...
notes: REFERENCE ORIGINAL — RIGHTS REMAIN WITH ORIGINAL CREATOR/PUBLISHER
```

# UAT and EVT Plan

## Owner-facing happy path

1. Create repository.
2. Run bootstrap.
3. Run doctor.
4. Run scan.
5. Review estimate report.
6. Run core acquisition.
7. Interrupt once and resume.
8. Search for Prahlāda, Dhruva, curriculum, comic, printable.
9. Open safe local PDF through the OS, not public static hosting.
10. Run report.
11. Back up to an external location.
12. Verify restore sample.

## Acceptance observations

- Commands are understandable.
- Progress is clear.
- Current and remaining bytes are visible.
- Failures do not erase progress.
- Logs identify exact resource IDs.
- Core run contains no audio/video.
- Disk never approaches reserve.
- Third-party files remain unchanged.
- Original-work notice generator uses approved identity.
- No huge files appear in Git status or Cursor context.

## Failure exercises

- disconnect network;
- stop process;
- reduce free-space threshold artificially;
- corrupt a `.part`;
- change test server ETag;
- add malicious archive fixture;
- attempt Git add of a PDF;
- request a third-party copyright stamp;
- run backup twice.

## Evidence

Capture:

- command;
- timestamp;
- exit code;
- screenshot;
- report path;
- relevant log excerpt;
- pass/fail;
- defect ID.

# Definition of Done

The repository is complete only when:

- clean bootstrap works on Windows;
- dependency lock is committed;
- source adapter has stable fixtures;
- scan downloads no bodies;
- estimate downloads no bodies;
- core excludes audio/video;
- first safe batch downloads or a hard blocker is evidenced;
- disk safety works during streaming;
- resume works;
- every finalized file is verified;
- suspicious files quarantine;
- originals are immutable;
- Git guards pass;
- SQLite index and reports reconcile;
- backup and restore verification pass;
- copyright module distinguishes original and third-party files;
- existing-nine-stories intake exists;
- automated tests pass;
- independent review and UAT have no unresolved critical/high defects;
- all documentation commands match actual behavior.
